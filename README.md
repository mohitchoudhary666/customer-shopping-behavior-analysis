# Customer Shopping Behavior Analysis

A lightweight demo project that explores customer shopping behavior using a synthetic dataset. The repository includes data, a Jupyter notebook for exploratory analysis, SQL query examples, a preprocessing script, and placeholders for dashboards/reports.

---

## ?? Repository Structure

- **`data/`**: Raw and transformed datasets (`.csv`).
  - `customer_shopping_behavior.csv` (sample raw data)
  - `customer_shopping_behavior_cleaned.csv` (generated by the preprocessing script)
- **`notebooks/`**: Jupyter notebooks for analysis.
  - `customer_shopping_behaviour_analysis.ipynb` (exploratory analysis)
- **`sql/`**: Example SQL queries for analytics.
  - `customer_behavior_sql_queries.sql`
- **`scripts/`**: Python scripts that support data prep and analysis.
  - `data_preprocessing.py` (cleaning + feature engineering)
- **`dashboard/`**: Placeholder for Power BI dashboard.
  - `customer_behavior_dashboard.pbix`
- **`reports/`**: Placeholder PDF reports.
  - `project_report.pdf`
  - `presentation.pdf`

## ?? Getting Started (Local)

> This project is designed to run locally using Python.

### 1) Install dependencies

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2) Preprocess the data

```powershell
python scripts\data_preprocessing.py
```

This generates `data/customer_shopping_behavior_cleaned.csv`.

### 3) Run the notebook

Open:

- `notebooks/customer_shopping_behaviour_analysis.ipynb`

and run the cells to inspect the data and visuals.

## ?? What’s Included

### ? Dataset (Synthetic)
- `customer_shopping_behavior.csv` contains customer transactions with fields like:
  - `customer_id`, `gender`, `age`, `location`, `purchase_date`, `product_category`, `amount`, `payment_method`

### ? Preprocessing
- `scripts/data_preprocessing.py`:
  - parses dates
  - standardizes text fields
  - adds derived columns (`year`, `month`)

### ? Notebook
- Basic exploratory analysis using `pandas`, `seaborn`, and `matplotlib`.

### ? SQL Queries
- Example queries for summary statistics and behavior analysis.
