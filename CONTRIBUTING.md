# Contributing

Thanks for your interest in contributing! This is a demo project, but you can still:

- Improve the dataset (more realistic fields, more records)
- Add additional notebooks or analysis scripts
- Expand the SQL query library
- Add data validation tests

### How to contribute

1. Fork the repo on GitHub.
2. Create a new branch: `git checkout -b my-feature`.
3. Make your changes and commit.
4. Open a pull request.
